# python Django Sistema de cadastrado

Este repositório contém uma aplicação simples construído usando Django. O objetivo deste repositório é praticar e construir um sismples sistema de visualização de usuarios cadastrados, usando python.

## Instalação

1. Clone o repositório:

```bash
git https://github.com/bispobr/python-django-sistema-de-cadastro.git
```
2. instale o django atraves do pip python
2. execute o arquivo manager.py

## Como usar

1. A aplicação está acessivem atraves do Link http://localhost:8000
