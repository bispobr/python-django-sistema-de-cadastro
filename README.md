# Sistema de Cadastro com Django

Aplicação web desenvolvida em Python utilizando Django para praticar a construção de um sistema simples de cadastro e visualização de usuários.

O projeto faz parte dos estudos de desenvolvimento web com Python e Django.

## Funcionalidades

- Cadastro de usuários
- Visualização de usuários cadastrados
- Interface web para interação com a aplicação

## Tecnologias

- Python
- Django

## Requisitos

- Python 3+
- Django

## Instalação

Clone o repositório:

```bash
git clone https://github.com/bispobr/python-django-sistema-de-cadastro.git
cd python-django-sistema-de-cadastro
```

Instale o Django:

```bash
pip install django
```

## Executando o projeto

Inicie o servidor de desenvolvimento Django:

```bash
python manage.py runserver
```

A aplicação estará disponível em:

```text
http://localhost:8000
```

## Como utilizar

Após iniciar o servidor, acesse a aplicação pelo navegador utilizando o endereço local informado acima.

A aplicação permite consultar os usuários cadastrados e realizar as operações de cadastro disponibilizadas pelo projeto.

## Estrutura

O projeto utiliza a estrutura padrão de uma aplicação Django. O arquivo `manage.py` é utilizado como ponto de entrada para os comandos de gerenciamento do projeto.

Os detalhes das aplicações, modelos, views e templates devem ser consultados diretamente na estrutura atual do código.

## Comandos úteis

Iniciar o servidor de desenvolvimento:

```bash
python manage.py runserver
```

Executar as migrações, caso existam no projeto:

```bash
python manage.py migrate
```
